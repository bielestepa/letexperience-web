# LET Experience — web oficial

Web estática oficial de LET Experience.

## Edición sencilla

- El contenido principal está en `index.html`.
- Las imágenes están en la carpeta `assets/`.
- Para cambiar un texto: abre `index.html` en GitHub, pulsa el icono del lápiz, modifica el texto y guarda con **Commit changes**.
- Vercel publicará automáticamente los cambios cuando el repositorio esté conectado al proyecto.

## Enlaces principales

Los botones de reserva utilizan enlaces externos de PayPal y la Letsletter enlaza a la página de suscripción.
